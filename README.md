# Campus Canteen - Frontend

A React 19 single-page application built with Vite and Tailwind CSS for the Smart Campus Canteen Pre-Ordering & Live Token System.

## Features
- Real-time digital cafeteria menu with category filters and search
- Interactive slide-out cart drawer with instant token generation
- Live Token Board with automated refresh and sound cues
- Kitchen Staff Kanban Dashboard with order cooking lifecycle controls
- Student Order History & Active Token Status tracker

## Tech Stack
- React 19
- Vite
- Tailwind CSS
- Lucide React
- Axios

## Setup & Running Locally
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
